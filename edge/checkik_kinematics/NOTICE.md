# checkIk kinematics reuse

`kinematics.py`, `ik.py`, `safety.py`, `__init__.py`, and
`so101_new_calib.urdf` are copied from the user-provided `checkIk` workspace
folder for local FK/IK preview and simulation integration. The source folder
did not contain a license file for these files. Keep the original `checkIk`
folder as provenance and resolve licensing before redistributing these files
outside the project. The reused `RobotController` and direct hardware workers
are intentionally not bundled or invoked.
